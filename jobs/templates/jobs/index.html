Объектнинг бутун папкасини ёки ZIP / RAR архивини ташланг — ичидаги ҳар бир папка алоҳида смета бўлади. Аввал файллар очилиб, жуфтланади — текширгач, «Ҳисоблашни бошлаш»ни ўзингиз босасиз. Натижа битта ZIP да, папкалар тузилиши сақланган ҳолда.

Мактаб 2-блок/
├─ 1. Архитектура/
│   ├─ ар_локал.xls          ← локал (иш ҳажмлари)
│   └─ ар_ресурс.xls         ← ресурс (нархлар)
├─ 2. Электр/
│   ├─ Ички тармоқ/
│   │   ├─ лок.xls
│   │   └─ рес.xls
│   └─ Ташқи тармоқ/
│       ├─ смета.xls         ← 2 лист: локал + ресурс
│       └─ смета_narxlandi.xlsx  ← олинмайди
└─ Умумий ҳисоб.xlsx        ← смета эмас, ўтказилади
  • Ҳар бир смета — ўз папкасида: битта локал (Форма 5, иш ҳажмлари) ва битта ресурс (Форма 6а, нархлар). Иккаласи битта файлнинг икки листида бўлса ҳам бўлади.
  • Файл номи аҳамиятсиз. «локал», «рес», «lokal» деб ёзиш шарт эмас — тизим файл ичидаги жадвалга қараб ажратади: сарлавҳада нарх устуни («Цена», «Сметная стоимость») бор лист — ресурс, йўғи — локал.
  • Папкалар чуқурлиги ихтиёрий: «Блок / Қисм / Бўлим» каби ичма-ич бўлиши мумкин.
  • Олинмайди: олдинги натижалар («…_narxlandi»), Excel очиқлигида пайдо бўладиган «~$…» файллар, PDF, расм ва бошқа Excel бўлмаган файллар (кўрсатилмайди ҳам). Умумий ҳисоб файллари смета эмас деб белгиланади.
  • Архив (ZIP, RAR): ичма-ич бўлса ҳам очилади (ZIP ичида RAR…), ичидаги Excel'лар архив номли папкада.
  • Натижа: ҳар бир локал ёнида «локал номи_narxlandi.xlsx» — қўлда шундай сақлагандек.
